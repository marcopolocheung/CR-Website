06 / Implementation

Working rules

Task labels

Dashboard, Cash count, Inventory. No greetings, pep talks or decorative instruction lines.

Three surface levels

Frame, work surface, control. Reserve the strongest elevation for the active work surface.

Stable data

Fields, numbers and tables stay level and untextured. Decorative grain is confined to framing.

Consistent icons

One stroke weight and silhouette family. Use icons to identify tasks and actions, not to replace essential labels.

Limited accent

Use the complementary color for icon tiles, selection and framing details. Keep the main action red.

Accessible states

Visible focus, 48px controls, readable color pairs, wrapped labels and reduced-motion support.
